# Visual music corpus: licence notes

The manifest contains 20 counted recordings plus one auxiliary comparison track. The
20 counted tracks are:

- 18 Kevin MacLeod recordings downloaded from the official Incompetech catalogue:
  `carefree`, `tafi-maradi`, `cantina-blues`, `valse-gymnopedie`, `funky-boxstep`,
  `cloud-dancer`, `night-in-venice`, `bossa-bossa`, `dub-eastern`, `raw`, `blue-ska`,
  `the-britons`, `still-pickin`, `exotic-battle`, `dama-may`, `scp-outer-thoughts`,
  `android-sock-hop`, and `ritual`.
- 2 CC0 recordings on Wikimedia Commons: `couperin-harpsichord` and `drozerix-rndd`.

Incompetech's [official licence page](https://incompetech.com/music/royalty-free/licenses/)
states that its free Creative Commons option requires credit. The current track pages
and catalogue identify the artist, title, ISRC and download; the manifest records each
track page in `source_url`, the direct MP3 in `download_url`, and the same CC BY 4.0
licence URL. Use the per-track `attribution` value from the JSON when publishing or
redistributing an output. The credit pattern is:

`<title> Kevin MacLeod (incompetech.com). Licensed under Creative Commons: By Attribution 4.0 License.`

The Couperin Commons page names David Joseph Stith as performer and declares the hosted
recording CC0 1.0. The Drozerix page identifies the track as tracker chiptune, names
Drozerix, and declares the hosted FLAC CC0 1.0. These are source-page declarations;
CC0 removes attribution obligations, though retaining the artist and source links is
good provenance practice.

`mozart-symphony-29` is retained as an auxiliary comparison because the Commons file
page declares CC0 for the hosted file, while the underlying performance provenance is
less explicit. It is excluded from `target_counted_tracks`; a public-domain composition
does not by itself establish that a particular recording is public domain.

The original 21 acquisition files remain in the OS temporary directory named by
`download_root` while the runs are active. Byte-identical copies of the 20 counted
tracks are retained locally under
`artifacts/visual_audit/2026-09-03/audio/` and ignored by Git; their `local_path` values
in the manifest point to those copies, and each copied file was rechecked against its
recorded SHA-256.
The Mozart file remains at its temporary path and is marked `temporary_auxiliary` in
the manifest. No Gene Autry or other rejected source is included. The source files were
decoded successfully with `ffprobe`; an HTML response would not pass that media decode
check. The URLs and hashes are recorded in
[visual_music_corpus_20.json](visual_music_corpus_20.json).

These notes document the declarations visible on the linked source pages for this
research run. They are not a legal opinion or a guarantee against future takedowns,
metadata changes, or third-party claims. Recheck the source pages and keep the credit
when a rendered result is distributed.
