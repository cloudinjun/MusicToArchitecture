# Security policy

Report suspected vulnerabilities privately through the repository host's security
advisory feature or directly to the maintainer. Do not include secrets, private audio,
or sensitive project data in a public issue.

This software processes uploaded MP3 files and can invoke local Blender. Treat uploads
as untrusted, keep the service local unless it has been hardened for deployment, and
review generated file paths before exposing the API publicly.

The architectural and structural checks are research outputs. They do not establish
code compliance, life safety, structural safety, permit readiness, or construction
readiness.
