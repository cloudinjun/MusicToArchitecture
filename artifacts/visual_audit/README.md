# Visual audit evidence

The repository keeps a compact, reviewable surface from the 20-recording visual audit:
comparison cards, aggregate reports, per-track geometry measurements, GLB parity records,
and verification notes.

Raw audio, repeated GLBs, full render sequences, native scenes, and rejected intermediate
rounds remain in the local audit store and are ignored by Git. Their hashes and outcomes
remain recorded in the committed summaries. This keeps the public repository reproducible
at the claim level without duplicating gigabytes of generated media.

See [`docs/experiments/visual_music_audit_20.md`](../../docs/experiments/visual_music_audit_20.md)
